# Project Title (To Be Determined)

This project aims to provide a suite of client-side applications (mobile, web, desktop, Mac) that allow users to store and manage their data (images, videos, etc.) in their own cloud storage providers (e.g., S3, Azure).

## Project Structure

-   `/mobile_app`: Contains the mobile application.
-   `/web_app`: Contains the web application.
-   `/desktop_app`: Contains the desktop application.
-   `/mac_app`: Contains the Mac application.
-   `/shared_lib`: Contains shared libraries and common code used across the different applications.

This project is client-side based and does not require any server-side components in the cloud beyond the user's own storage.
